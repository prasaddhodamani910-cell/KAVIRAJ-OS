Explore Architecture View Source Code

Engineering Mastery

AArch64 Hardware

Directly interfaces with ARMv8-A architecture, configuring EL1 exception vector tables, GICv2 interrupt routing, and physical MMU.

Preemptive Kernel

Utilizes the ARM Generic Physical Timer to generate hardware ticks at 62.5MHz, enabling robust context switching and multitasking.

Custom Shell & VFS

Features a built-in interactive REPL shell and a custom Virtual Filesystem supporting real-time text editing, scripts, and processes.
